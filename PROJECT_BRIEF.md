# Flagship direction

Build causal forecasting and uncertainty tools that remain interpretable under regime changes, using fundamental ML and useful integrations.

Read src/studio.py, docs/study.json and reports/applied-study.md before adding features. Extend the applied application and its usable interface. Preserve legacy public APIs.

## Next priorities

- Repeat the volatility forecast protocol across independently generated datasets; freeze selection and report uncertainty.
- Add feature ablations and compare likelihood-aware training objectives without tuning on the final holdout.
- Provide a validated user-CSV forecasting adapter and compare the same causal protocol on licensed public data.

Every milestone must answer a substantive applied question, compare a meaningful baseline, measure actual results and expose the result in the existing studio when relevant. Avoid isolated textbook scripts. Preserve negative findings. Keep artifacts compact and dependencies pinned; no API keys, extra agents or model sessions.
