# ML03 - Forecast feature ablation

## Question

Which causal feature groups support next-period squared-return forecasts in
stable and shifted synthetic histories? Does choosing a smaller feature set by
validation improve on full-feature ridge and a feature-free training mean?

## Method

Use 20 independent process seeds, 200-219, disjoint from the earlier seed-73
illustration and seeds-100-119 ensemble. Each seed produces 2,000 Gaussian
GARCH-like returns. Stable and stress histories share innovations within a seed;
different process seeds are independent sampling units. Baseline coefficients
are (omega, alpha, beta)=(0.025, 0.10, 0.84). The stress process changes at day
1450 to (0.12, 0.16, 0.84), with unit persistence and no finite stationary
unconditional variance. All histories, including extreme paths, are retained.

Features observed at close t predict r[t+1]^2. The fixed groups are:

| Group removed | Original columns | Features |
| --- | --- | --- |
| Latest shock | 0 | Latest squared return |
| Smoothed magnitude | 1, 2, 4 | 5/20-day realized variance; 20-day mean absolute return |
| Signed returns | 3, 5 | Latest return; 5-day mean return |

Each removal is separate, not cumulative. Full ridge retains all six columns.
The training-mean baseline uses no features. Every ridge variant fits its own
scaling and coefficients on training targets <1000 (979 rows). Validation
targets 1001-1199 (199 rows) select alpha from [0.01, 1, 10, 100] by MSE for each
variant. A second validation-only comparison selects the variant with the lowest
selected validation MSE. Ties use the first candidate, full ridge first, then
the three removals in the order above. No validation refit occurs.

Selection finishes before calibration targets 1201-1449 (249 rows) set a 90%
absolute-residual radius separately for each model, including training mean.
The radius is the 225th ordered residual, ceil((249+1)*0.9); the lower endpoint
is clipped at zero. The validation-selected procedure uses its chosen model's
calibrated radius. Test targets 1451-1999 (549 rows) score all frozen models;
there are no expanding refits in this ablation. Boundary targets 1000, 1200 and
1450 are excluded. No test error, coverage, or ensemble summary selects a
feature variant, penalty, group definition or seed exclusion.

MAE, RMSE, QLIKE, positivity-floor fractions, coverage, radius and actual mean
interval width are recorded per model/seed. QLIKE is
mean(log(max(prediction, 1e-5)) + target/max(prediction, 1e-5)); target-only terms
are omitted. Calibration supplies intervals only, not model ranking. Paired
differences subtract full ridge on the same history. Each seed has equal weight;
sample SD uses ddof=1, MCSE=SD/sqrt(20), and p10/p90 use linear empirical
quantiles. Days and stable/stress outcomes are not independent replicates.

Smoothed magnitude is the most consequential removal in this fixed comparison:
stable paired RMSE p10-p90 is +0.003619 to +0.035061, and stress is +0.506108 to
+8.212432. Removing signed returns or latest squared return changes stable
average RMSE little. Overlapping magnitude summaries can substitute for a
single squared-return feature. This is conditional predictive evidence for
these refitted ridge models, not a proof of irrelevance or causal importance.

Validation chooses full ridge in 3 pairs, latest-shock removal in 4,
smoothed-magnitude removal in 1, and signed-return removal in 12. Choices and
calibration radii match within each stable/stress pair because their pre-break
data match. The selected procedure ties full ridge in 3 seeds in each regime.
It does not uniformly improve either mean loss or the number of wins. Full
ridge beats training mean on test RMSE in all 20 seeds in each regime, but
under stress its mean QLIKE is worse, 650.34 versus 47.64.

The stress tails and flooring failures matter. Full-ridge stress RMSE has
p10-p90 7.31-70.74, but maximum 455.75. At seed 200, full-ridge stress QLIKE is
12,941.32 and 5/549 forecasts hit the positivity floor. Without smoothed
magnitude, seed 209 QLIKE reaches 573,322.20 with 14/549 floor hits. No such
path is removed. Higher coverage for a weak model does not by itself indicate
better uncertainty: widths and point errors must also be inspected. None of
the removals restores nominal 90% coverage under stress.

## Checks and limitations

The test suite checks actual column deletion and training-only fit inputs,
both validation-selection levels and deterministic ties, the exact calibration
rank, selected-model score identity, paired aggregation, and studio chart/table
alignment. Independent mutations of test features, test targets, or both leave
all validation selections and calibration radii identical while errors change.
Changing calibration targets changes radii while point errors and selections
stay fixed. A validation-target mutation changes selection evidence, providing
a positive sensitivity control. Existing legacy numerical checks remain intact.

The saved `feature_ablation_protocol.isolation_audit` makes those boundaries
inspectable outside the test runner. On stable seed 200, separate interventions
on already constructed rows give the following measured maximum absolute
changes across the six reported models:

| Intervention | Selection unchanged | Calibration radius change | Test RMSE change |
| --- | --- | ---: | ---: |
| Test features replaced by 100 + 7*x | Yes | 0 | 92.723770 |
| Test targets increased by 1000 | Yes | 0 | 999.341396 |
| Calibration targets increased by 1000 | Yes | 999.928650 | 0 |
| Excluded boundary features and targets increased by 1000 | Yes | 0 | 0 |

The excluded-row intervention leaves the entire record identical. Sensitivity
of test errors and calibration radii shows that the checks are not simply
comparing inert outputs. These deterministic interventions are implementation
diagnostics on one history, not additional independent forecasting evidence.
They do not prove the provenance or causality of arbitrary supplied features.
Each record now exports exact first/last target indices and excluded indices;
misaligned arrays, nonfinite values, duplicate/unordered/fractional target
indices and empty fixed windows are rejected rather than silently scored.
Both ablation studio cases expose the audit in their method details, with full
measurements available in the JSON download. Unit tests independently check the
training-mean control against its analytical test RMSE and verify that changing
all feature values cannot alter that feature-free baseline.

These are synthetic histories from one generator and one stress mechanism;
there is no claim of real-world forecasting accuracy or novelty. The experiment
measures a penalty-reselected training procedure, so it does not isolate only
the effect of deleting a column at a fixed coefficient vector. Correlated
features and joint group deletion prevent unique feature attribution.

Reusing 199 validation targets to select both alpha and variant can overfit
validation. Test summaries are descriptive evidence about that frozen procedure;
choosing a new production subset from them would need a new confirmation
ensemble. Twenty seeds offer limited tail resolution; MCSE and empirical
quantiles do not establish statistical significance. Serial dependence and
shift violate ordinary exchangeable conformal assumptions; coverage is an
empirical diagnostic. Neural features, alternative training objectives and
licensed public datasets remain separate future comparisons.

Primary methodological guidance is linked in [REFERENCES.md](../REFERENCES.md):
the scikit-learn maintainers' feature-selection leakage guidance and Hyndman
and Athanasopoulos on evaluating future forecasts. Existing conformal references
describe the assumptions which this synthetic shift violates.

## What the author should understand for an interview

Trace the four windows: training learns scales and coefficients, validation
selects penalties and feature variants, calibration sets residual thresholds,
and test evaluates the frozen procedure. Explain why all variants may be
reported on test while choosing a winner there would contaminate selection.
Describe why group removal requires refitting and why correlated predictors
make its interpretation conditional rather than causal.

Explain the training-mean control, matched full-feature baseline, seed pairing,
and the difference between dataset SD, MCSE, seed quantiles and interval
coverage. Be able to explain the negative result: validation selection yields
almost unchanged stable RMSE, worsens average stress RMSE, and does not repair
coverage. Finally, demonstrate how near-zero variance forecasts dominate QLIKE
and why counts of wins can disagree with average error differences.
