# RegimeLab

**A forecasting model can look reliable until the process generating its data changes. RegimeLab makes that failure measurable.**

The project compares simple, linear and neural forecasts of next-period squared returns. A chronological experiment separates model selection, uncertainty calibration and evaluation, then subjects the forecasts to an intentionally persistent volatility shift.

[Explore the forecasting dashboard](https://fyodoramanov1.github.io/statistical-learning-lab/) · [Read the study](reports/applied-study.md)

## Forecasting task

At the close of time t, six causal features predict r[t+1]²: the latest squared return, five- and twenty-day realized variance, the latest return, twenty-day mean absolute return and five-day mean return.

The data are generated by a synthetic GARCH-like process. The baseline coefficients are (ω, α, β) = (0.025, 0.10, 0.84). At day 1,450 the stress configuration changes to (0.12, 0.16, 0.84). Its α + β = 1 intentionally creates a persistent, nonstationary stress process without a finite stationary unconditional variance.

## Comparison design

- **Baselines:** training-set mean and lagged squared return.
- **Fixed models:** ridge regression and a 6 → 12 → 1 tanh network trained on a transformed variance target.
- **Adaptation:** expanding-window ridge, refitted every 60 newly observed targets with its selected penalty frozen.
- **Evaluation:** chronological train, validation, calibration and test windows with embargoed boundaries; scaling fitted on training data only.
- **Uncertainty:** nominal 90% split-conformal residual bands around the frozen ridge model.

MAE, RMSE and QLIKE are reported together. They emphasize different forecasting errors and can rank the same models differently.

## A result worth inspecting

Selected **stress-period** results from the saved seed:

| Model | MAE | RMSE | QLIKE |
|---|---:|---:|---:|
| Training mean | 10.014 | 21.642 | 25.715 |
| Frozen ridge | 9.191 | 19.813 | 36,624.059 |
| Neural network | 9.852 | 21.502 | 17.807 |
| Expanding ridge | 9.839 | 18.340 | 3.184 |

Adaptation improves RMSE and QLIKE in this comparison, while frozen ridge has lower MAE. The very large ridge QLIKE exposes sensitivity to tiny positive variance predictions; the implementation applies a 10⁻⁵ positivity floor.

The nominal 90% bands cover **91.07%** of observations in the stable evaluation window and only **18.76%** after the shift. The interface shows the interval failures alongside the forecasts rather than hiding them behind an overall score.

## Interpretation

These results come from one synthetic process and seed, not a market backtest or an independent multi-dataset benchmark. Chronological dependence and distribution shift break the exchangeability assumptions behind ordinary split-conformal guarantees; the displayed coverage is an empirical diagnostic.

The natural next study is to repeat the full selection and evaluation process over independent seeds and different shift mechanisms before drawing a broader conclusion about model rankings.

## Run locally

Use Python 3.12. From the repository root:

```bash
python -m venv .venv
```

Activate it with `.venv/Scripts/Activate.ps1` in PowerShell or
`source .venv/bin/activate` on macOS/Linux. Then run:

```bash
python -m pip install -r requirements.txt
python -m http.server 8000 --directory docs
```

Open
<http://localhost:8000> to explore the bundled study without recomputing it.

To regenerate the study or compare it with the saved artifact:

```bash
python src/studio.py --out docs/study.json
python src/studio.py --check docs/study.json
```

The browser displays recorded experiments; it does not run the Python simulation.
Use its charts, case selector and data exports to inspect the results.
